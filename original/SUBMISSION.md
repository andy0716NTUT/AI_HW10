# 作業繳交內容（請自行補上學號）

**標題：北科大 [學號] 資工四 [姓名] AI Agent LLM Wiki 與教學簡報**

## 主題與介紹
AI Agent 運作原理。以 5 篇技術文件為資料來源建立 6 個條目的本機結構化 Wiki，介紹 Agent 定義、元件、工具呼叫、Graph、常見模式與安全驗證。

## 成果
- Wiki：`index.html`（來源結構化資料：`wiki.json`）
- 教學簡報：`slides.html`（10 頁，可用鍵盤左右鍵操作）
- Graph、執行與檢查、反思：`workflow.html`
- 靜態驗證紀錄：`validation.json`

**注意：本機 HTML 檔尚非公開網址。** 要交線上連結，可以把整個資料夾上傳到 GitHub Pages 或其他靜態網站服務，並把這裡的檔案路徑換成公開 URL。

## 反思
最容易產生問題的是整理後的 Wiki 內容和投影片來源對應不明，因此把來源檢查提前到 Wiki 條目建立階段，為每個條目指定來源 ID。Graph 在投影片生成之前新增「Wiki 來源映射檢查」節點；檢查失敗先回來源或摘要節點，不直接用缺少依據的內容生成投影片。

## 實作誠實聲明
此成果為 LLM 輔助製作的本機結構化 Wiki 與靜態 HTML 簡報；並無聲稱連接學校指定的 LLM Wiki 平台或執行真實自動化 LangGraph。
